# 🥋 Федерация Рукопашного Боя - Веб-сайт

## 📋 Функционал

### 🌐 Публичная часть
- **Главная страница** с лентой новостей и статистикой
- **Система новостей** с поддержкой нескольких фото в одном посте
- **Детальные страницы** новостей с галереей изображений
- **Страница тренеров** с информацией о составе
- **Страница спортсменов** с достижениями
- **Расписание тренировок**
- **Адаптивный дизайн** для всех устройств

### 🔐 Админ-панель
- **Управление новостями** (добавление, редактирование, удаление)
- **Загрузка изображений** (поддержка нескольких файлов)
- **Управление тренерами** и спортсменами
- **Безопасная аутентификация** с сессиями
- **Валидация загружаемых файлов**

### 🛠 Технические возможности
- **Файловая база данных** (JSON) без сложных настроек
- **Система загрузки файлов** с уникальными именами
- **Поддержка популярных форматов** изображений
- **Автоматическое резервирование** данных
- **Простая миграция** на любой хостинг
